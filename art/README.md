# World Draft visual kit

- **studio-auction.png** — Studio playtest capture of the sealed transfer auction.
- **studio-match.png** — Studio playtest capture, round 1 route selection on the Continental Cup board.

- **world-draft-icon.png** — 512 × 512, [Creator Hub game icon](https://create.roblox.com/docs/production/publishing/experience-icons). SVG is the editable master.
- **world-draft-thumb.png** — 1920 × 1080, [Creator Hub thumbnail](https://create.roblox.com/docs/production/publishing/thumbnails) / portfolio cover. Original key art inspired by the actual in-game board layout and figure colors. This is an illustration, not a Studio screenshot.
- Art direction: daylight stadium, cream tile faces, mint and sky-blue movement cues, five league colors, sports-broadcast typography. Figure number and tile code identify pieces independently of color. Models and lighting inside Roblox are generated by Luau and require no uploaded assets.
- Map and cover land mask: [Natural Earth 1:110m land](https://www.naturalearthdata.com/downloads/110m-physical-vectors/), [public domain](https://www.naturalearthdata.com/about/terms-of-use/). Source package: Natural Earth Vector v5.1.2, `geojson/ne_110m_land.geojson`, SHA-256 `9e0729ee253ca7d7a5c4ae9395fb1902264c5377c52e224d13dd85010e2835d9`. Run `python3 scripts/make-map.py /path/to/ne_110m_land.geojson` to regenerate the Luau spans.
- Runtime feedback uses Roblox's bundled sound files. No use of external club badges, player portraits or board textures. The cover uses system font fallback; no font files are distributed.
- AI assistance: Codex supported research, source authoring and automated QA setup. Cover masters are editable programmatically drawn vectors generated from game data; no images from other games or the reference listing were reused.

Rebuild the editable masters: `python3 scripts/make-key-art.py`. The checked-in PNGs were rasterized with @resvg/resvg-js 2.6.2 and system fonts. Run `node scripts/raster-key-art.cjs` with that package available to Node to recreate them.
