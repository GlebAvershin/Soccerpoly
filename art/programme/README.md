# Иллюстрации клеток

Два оригинальных атласа созданы с ImageGen для Footbolapolia. Художественное задание для стадионов — горизонтальные винтажные футбольные литографии, силуэт трибун и прожекторов, крупные цветовые пятна и свободное место для клубной формы. Для событий — отдельные композиции с конвертом, билетами, выездным багажом и скамейкой. Названия и цены накладываются при сборке.

Скрипт нарезает атласы, рисует клубные футболки и формирует палитры для клиента. Нужны Python, Pillow и системный Arial Bold на macOS.

```sh
python3 scripts/pack-programme.py
```
