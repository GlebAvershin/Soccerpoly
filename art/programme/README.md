# Иллюстрации клеток

У каждой из 32 клеток турнира есть иллюстрация. В `grounds.svg` хранятся пять архитектурных силуэтов и шесть символов событий. Генератор `scripts/programme_prints.py` собирает их в серию спортивных афиш. У 20 клубов собственная форма, цвета и рисунок ткани. Четыре стадиона отличаются очертаниями крыш и фасадов. Три клетки «Шанс» используют общую иконку карт в разных цветах.

Для поля собирается печать 320 × 128, для открытого досье — 768 × 307. Изображение формы 256 × 256 сохраняет пропорции на клетках разного размера. Изображения встроены в сборку. Название и стоимость набраны средствами Roblox на отдельных плашках и переводятся во время игры.

Для повторной сборки нужны Python с Pillow и resvg-py, а также zstd в PATH.

```sh
python3 scripts/pack-programme.py
```

Площадь вокруг стадиона нарисована в Magnific. На иллюстрации видны медные крыши павильонов, террасы и бассейны. Редактируемые модели трибун, входных ротонд и основания доски находятся в `art/stadium-kit.blend`. Генератор подготавливает текстуру площади размером 1024 × 1024 для плоскости под объёмными трибунами.
