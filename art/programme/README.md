# Иллюстрации клеток

Атласы stadiums.png и events.png содержат оригинальные иллюстрации для Soccerpoly, созданные с ImageGen. Клубную нашивку задают кривые в kit.svg. Шаблон задаёт воротник, рукава, складки, эмалевую подложку и края. Генератор подставляет для 20 клубов цвета и крой рисунка.

На поле используются сглаженные миниатюры 384 × 144. В досье открывается отдельная панорама 768 × 256. Нашивки 256 × 256 накладываются отдельно с сохранением пропорций. Пакет содержит полноцветные RGBA-данные с потерями только на этапе изменения размера изображения. Zstandard сжимает готовые пиксели обратимо. Названия и цены набраны средствами Roblox.

Для повторной сборки нужны Python с Pillow и resvg-py, а также zstd в PATH.

```sh
python3 scripts/pack-programme.py
```

Источник окружения — оригинальная иллюстрация вечернего стадионного квартала в stadium-district.png, созданная с ImageGen. Генератор приглушает цвет, смягчает наружные края и сохраняет текстуру 1024 × 1024. Клиент размещает её на плоскости под объёмными трибунами.
