# Эксперимент с подсказкой тренера

**Гипотеза.** Одна строка в первый ход помогает новичку понять, зачем покупать свободный клуб. Меняется подсказка. Карты, экономика, ход ботов и таймер одинаковы для обеих групп.

| Параметр | Определение |
| --- | --- |
| Популяция | Первый solo-сезон игрока после регистрации в эксперименте. Совместные матчи не включаются |
| Единица | Игрок. Стабильный хеш Roblox ID и версии эксперимента. В отчёте один раз на игрока, по первому назначению |
| A / B | A видит существующий экран маршрута. B получает фразу о сборе за посещение клуба |
| Основной показатель | Первый ручной ход раньше 90 секунд после назначения, в том же матче. Тайм-аут и бот не считаются за человека |
| Ограничение | Завершение назначенного сезона за 20 минут. Допустимая просадка −3 п.п. абсолютных |
| Дополнительные метрики | Покупка за 7 минут, рематч, D1 в окне 24–48 часов. Разбивки по устройству и источнику исследовательские |
| План выборки | При 65% активации, MDE +5 п.п., α=.05 и мощности 80% нужно 1 377 на плечо. Для завершения с базой 64%, нулевым реальным сдвигом и нижней границей двустороннего 95% интервала −3 п.п. нужно около 4 019 на плечо |
| Проверка решения | До эффекта проверить SRM с порогом .01, дрейф назначения и полноту данных. При достижении размера выборки требовать нижнюю границу эффекта >0 по активации и >−3 п.п. по завершению |
| Запуск | В Studio распределение работает по умолчанию. На опубликованной тестовой копии оно включается атрибутом Workspace `CoachExperimentEnabled` |

В синтетическом наборе по 1 800 назначений в каждой группе. Активация 64,83% → 73,72%, разница +8,89 п.п., 95% ДИ [5,88; 11,88]. Завершение +0,06 п.п., 95% ДИ [−3,08; 3,19]. Принятое правило даёт `hold_guardrail`. Эта выборка создана для проверки расчётов. Для решения о раскатке нужны реальные назначения и полный период наблюдений.

## Данные и воспроизводимость

```sh
make analytics
uv run scripts/check_notebook.py
uv run --python 3.12 --with pyspark==4.0.1 python analytics/spark_parity.py --events .tools/synthetic-events.jsonl
```

- `analytics/simulate.luau` создаёт 3 600 назначенных участников с заданными параметрами поведения и 1 200 партий с ботами по настоящей модели правил. Идентификаторы искусственные. В игровом движке назначение, ход, покупка, исход матча, тайм-ауты и завершение логируются через Roblox Analytics.
- Нормализованные JSONL поля перечислены в `analytics/pipeline.py`. `event_id`, `player_id` и `session_id` должны быть стабильными псевдонимами. Для закрытого теста используются `dataset=playtest` и параметр `--cohort-dataset playtest` вместе с симуляционными строками для экономической витрины. Связь с сырым экспортом и источником захода нужно проверить в среде проекта.
- SQL оставляет первое назначение и использует левое соединение, поэтому выход из игры не исчезает из знаменателя. Дубликаты с тем же содержимым удаляются, конфликтующие версии событий и дрейф назначения останавливают сборку. D1 исключает участников без полного окна наблюдения. Lineage хранит входной хеш и путь от событий до каждой витрины.
- `segments.csv` и `economy.csv` готовы к импорту в Tableau. Дашборд в `dist/analytics/index.html` можно открыть локально. SQL-таблицы сохраняются в SQLite. `.ipynb` повторяет запросы и объясняет решение.
- Для PySpark 4.0.1 нужен полный JDK 17 или новее. Укажи `JAVA_HOME` штатным способом. [Требования PySpark](https://spark.apache.org/docs/4.0.1/api/python/getting_started/install.html).
- `analytics/airflow/worlddraft_dag.py` запускает пересчёт в Airflow 3 из отдельной локальной рабочей директории. `WORLDDRAFT_REPO` указывает корень этого репозитория, `WORLDDRAFT_LUAU` путь к интерпретатору. Для размещения в облаке `analytics/redshift.sql` показывает, как загрузить готовый Parquet из S3 в staging и перепроверить строки перед заменой витрины. IAM и целевой регион задаются владельцем среды. [Airflow Task SDK](https://airflow.apache.org/docs/task-sdk/stable/api.html) · [Redshift COPY](https://docs.aws.amazon.com/redshift/latest/dg/copy-usage_notes-copy-from-columnar.html).

## Выводы из моделирования экономики

На двух местах боты имеют 3,47 клуба в среднем. На шести — 1,88. Сборы возрастают с 15,34 до 350,30 CR на стол за сезон. Следующий вопрос для закрытого теста — сколько времени проходит до первой покупки на полном столе и считают ли игроки упущенные клетки понятной конкуренцией. После этого можно менять количество контрактов или состав маршрутов. Совпадение среднего шанса гола по всем столам с расчётными 50% не требуется, потому что боты иногда выбирают фиксированный доход.

Игровая телеметрия начинается в Roblox. Привязка Amplitude, AppsFlyer, Sentry, Redshift, каталога Monte Carlo и внешнего Databricks workspace зависит от доступных сервисов и разрешённых данных. Синтетические каналы используются для работы фильтров. `analytics/amplitude_export.py` сохраняет пример HTTP V2 для ревью, включая миллисекунды, session ID и insert ID. `uv run scripts/check_sentry.py` проверяет событие в памяти. [Amplitude HTTP V2](https://amplitude.com/docs/apis/analytics/http-v2) · [Словарь полей AppsFlyer](https://support.appsflyer.com/hc/en-us/articles/208387843-Raw-data-field-dictionary).
