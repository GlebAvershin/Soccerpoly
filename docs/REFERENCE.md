На фото товара №466595657 видны карточки «Реала», «Барселоны», «Ливерпуля» и «Ювентуса». На фрагменте поля также узнаются «Манчестер Сити», ПСЖ и «Бавария». «Сантьяго Бернабеу» и Old Trafford подписаны как отдельные стадионы. На снимках виден фрагмент поля. В Footbolapolia v0.4 по три клуба из каждого из пяти ведущих европейских дивизионов. Для отбора использована сумма подписок на официальные аккаунты в пяти соцсетях из рейтинга CIES за май 2026. Сумма подписок может учитывать одного болельщика на нескольких площадках. Состав дивизионов сверён с календарями и таблицами сезона 2026/27. **Выбор в Roblox.** Вместо броска кубиков из физического набора игрок получает две известные цели. Сезон ограничен восемью раундами. На Matchday действие занимает один дополнительный выбор с показом вероятностей. Так партия остаётся понятной без чтения длинной инструкции. Проверка понимания за пять минут входит в сценарий закрытого теста.

3D-карта, тексты событий и итоговый счёт разработаны для Footbolapolia.
